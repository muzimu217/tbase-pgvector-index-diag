# pgvector 索引诊断与参数推荐需求规格说明书

## 1. 范围与目标

本说明书定义独立 SQL 工具集的需求：源码级 IVFFlat 构建内存预测、零参数全库体检、官方 lists/probes 起点推荐、输入安全、异常场景记录和可复现报告。工具不修改 pgvector 索引构建主路径，不把进程 RSS 预测成 pgvector 的 k-means 检查点，也不把静态目录风险写成 EXPLAIN 结果。

## 3. 非目标与升级规则

large 的 `real-threshold` 只证明后端检查点一致，不证明巨型索引成功构建；`reltuples` 只是统计估计，生产使用前应 ANALYZE；HNSW 不使用 IVFFlat 的 lists/probes/内存字段；`possible_seqscan` 必须配合具体 EXPLAIN。只有新增原始日志、SQL 结果或矩阵后，延期需求才能升级状态。

## 4. 需求追溯

RQ-101~104 绑定 `sql/02_memory_model.sql` 与 `tools/validate_memory_model.sh`；RQ-201~203 绑定 `sql/04_catalog_introspect.sql`、`sql/05_audit.sql` 和 G10 日志；RQ-401 绑定 `docs/04-数据与图表/raw-memory-errors/`；RQ-404 绑定 `report/figures/`、`report/build/`。每条需求的状态均可从这些文件独立复核。
