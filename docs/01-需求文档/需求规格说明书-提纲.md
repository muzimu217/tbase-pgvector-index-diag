# 需求规格说明书（提纲・方向二）

## 1. 背景与问题（从需求调研报告浓缩：三个时刻无工具，见其 §4）

## 2. 目标与非目标

- 主目标：源码级内存预测 + 零参数全库体检 + 参数推荐 + 构建耗时模型 + 异常场景预警。
- 非目标：不修改 pgvector 索引构建主路径（优化以补丁形态单独交付）；不做查询性能 benchmark（方向一范围）。

## 3. 需求清单（RQ）

### 3.1 内存预测（本方向最高价值）

| 编号 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|
| RQ-101 | 内存预测与 pgvector 实际报错一致 | 高 | ≥20 组 (rows,dims,lists) 预测 vs 实测误差 <5%，**必含旧公式失效场景**（G4） |
| RQ-102 | 公式源码级可追溯 | 高 | 每项分配标注 `ivfkmeans.c` 行号 |
| RQ-103 | 无魔数 | 高 | `3.0`/`0.05`/`4096` 等全部删除或给出依据 |

### 3.2 零参数体检

| 编号 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|
| RQ-201 | 一条 SQL 全库体检 | 高 | `audit_all_vector_indexes()` 零参数运行，从 pg_class/pg_attribute 自动取参（G10） |
| RQ-202 | 覆盖 ivfflat 与 hnsw | 高 | 两类索引均输出风险清单 |

### 3.3 参数推荐与构建耗时

| 编号 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|
| RQ-301 | lists/probes 推荐回归官方公式 | 高 | 与官方建议一致并说明理由（G3） |
| RQ-302 | 构建耗时可预估 | 中 | 耗时模型 + 三子阶段占比（G13） |

### 3.4 异常场景与测试

| 编号 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|
| RQ-401 | 低内存失败提前预警 | 高 | 预警值与实际报错值一致 |
| RQ-402 | 低召回/计划退化识别 | 高 | skewed 低召回、二级排序键退 Seq Scan 均可识别 |
| RQ-403 | TAP/回归测试 | 高 | 可运行、给出通过率含不通过项（G11） |
