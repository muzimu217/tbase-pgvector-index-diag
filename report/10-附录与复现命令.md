# 10. 附录与复现命令

矩阵验证：`MODE=real tools/validate_memory_model.sh`（小规模端点）或按脚本说明运行 `MODE=indirect`/`real-threshold`；SQL 冒烟：`tests/sql/001_memory_model_smoke.sql` 与 `tests/sql/002_audit_zero_param.sql`；本地静态检查：`tests/test_input_validation.sh`、`tests/test_memory_model_matrix.sh`。每次复现后执行 `shasum -c docs/04-数据与图表/SHA256SUMS`，并将端点日志与 case id 对齐。
