## G10 复现顺序

1. 执行 `tests/test_input_validation.sh`，确认空值、负数、小数和 SQL 注入在调用 `psql` 前被拒绝。
2. 在授权端点加载 `sql/02_memory_model.sql`、`sql/04_catalog_introspect.sql` 和 `sql/05_audit.sql`，确认 schema version 记录为 2、3、4。
3. 创建 1000 行 `vector(3)` 表和 IVFFlat/HNSW 索引，在事务内调用 `audit_all_vector_indexes()` 后回滚。
4. 检查 IVFFlat 行的 `lists=10`、recommended lists=1、recommended probes=4、predicted build memory=1 MB；检查 HNSW 的 IVFFlat 专属列为空。
5. 在 `report/figures/` 重新生成三张图，最后从 `report/build/` 执行 `shasum -a 256 -c SHA256SUMS`。

复现结果若缺少后端 stderr，只能标为 `blocked`；若端点不可达，只能标为 `model-only`。这两个状态都不能进入 observed 列，也不能被报告改写成 pass。

## 审计输出字段契约

| 字段组 | IVFFlat | HNSW | 解释边界 |
|---|---|---|---|
| 目录身份 | schema/table/index/type | schema/table/index/type | 来自系统目录 |
| 规模 | rows/dims/index bytes | rows/dims/index bytes | rows 使用 reltuples 估计 |
| lists | 实际与推荐值、偏离度 | 空 | HNSW 不应用 IVFFlat heuristic |
| 内存 | predicted 与 maintenance | 空 | 只预测 IVFFlat k-means 检查点 |
| probes | sqrt(lists) 起始建议 | 空 | 不是 recall 保证 |
| seqscan 风险 | 静态布尔标记 | 无 IVFFlat 规则 | 不是 EXPLAIN 结果 |

零参数函数通过 `pg_proc.pronargs=0` 断言，且测试事务最后执行 ROLLBACK；这两项都应在复现日志中保留。若用户需要生产计划结论，必须在此清单之外追加代表性 EXPLAIN、ANALYZE 和 recall 数据。
