# 6. 实验设计

实验设计先于执行冻结。G4 矩阵覆盖 rows、dims、lists 的小、中、大组合，并强制包含四个旧公式失效场景：目标容量大于实际行数、1536 维高 item 大小、8192 lists 的 lowerBound 主导项，以及 32768 lists 的超大矩阵。每组都要求预测值、观测值、误差和原始 stderr；误差门槛为 `<5%`。

验证按资源分层。15 组 small/saturated 在远端实际执行 CREATE INDEX 并捕获 pgvector 原始错误；5 组 large 使用 `real-threshold`，降低 `maintenance_work_mem` 到预测值以下，让 pgvector 在分配巨型数组前返回同源错误，从而避免 3.7 GiB 主机 OOM。后者证明检查点一致，不证明巨型索引已经成功构建。最终 20/20 通过，observed 与 predicted 逐组一致，绝对相对误差均为 0.0000%。

G10 使用 1000 行 `vector(3)` 表，同时创建 IVFFlat 与 HNSW 索引，在事务中调用零参数审计并回滚。验收包括函数 `pronargs=0`、IVFFlat `rows=1000/dims=3/lists=10/recommended_lists=1/recommended_probes=4`、HNSW 专属字段留空，以及完整输出与原始日志一致。TAP 摸底另行记录为 0/44 通过，其中 1 个 bailout、43 个未执行，不表述为 44 个失败。
