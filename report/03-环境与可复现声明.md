# 3. 环境与可复现声明

## 环境

目标端点、OpenTenBase 提交、端口和 pgvector 版本以 `PLAN.md` 与测试日志为准。W2 的原始后端输出位于 `docs/04-数据与图表/raw-memory-errors/`，零参数审计输出位于 `tests/audit-zero-param-20260818.log`。

## 复现原则

先执行 `tests/test_input_validation.sh`、`tests/test_memory_model_matrix.sh`，再在授权 OpenTenBase 端点执行 SQL 测试和 `tools/validate_memory_model.sh`。所有新运行写入独立目录；`MODE=auto` 不得把模型值填入 observed 列，`real-threshold` 必须在报告中标明降低内存阈值的方法。
